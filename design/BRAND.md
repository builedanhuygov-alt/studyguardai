# Brand — StudyGuard AI

## Positioning
**Your intelligent study companion**, not a surveillance webcam. Voice: calm,
academic, encouraging, premium. Think Headspace warmth + Linear precision +
Apple Health clarity.

## Logo
- **Wordmark + mark:** `design/assets/logo.svg` (book + focus spark, indigo→violet gradient).
- **Mark only:** `design/assets/logomark.svg` (app/desktop icon base).
- **Favicon:** `design/assets/favicon.svg`.
- The mark = an open **book** (learning) with a warm **spark** (AI insight). The
  spark is amber (`--streak-500`) to signal encouragement, not observation.

### Variations (specs)
| Variation | Use | Notes |
| --- | --- | --- |
| Full color | light backgrounds | gradient mark + ink wordmark |
| Reversed | dark backgrounds | white wordmark, keep gradient mark |
| Monochrome ink | print / watermark | single `#141922` |
| Monochrome white | photos/video | single `#FFFFFF` |
| Mark only | app icons, favicon, avatar | 1:1, 22% corner radius |

### Clear space & min size
Clear space = height of the mark's corner radius on all sides. Min wordmark
width 120px; min mark 24px.

## App / platform icons
- **Desktop (.ico):** generated by `packaging/windows/make_icon.py` (mark on
  gradient, 16–256px). Replace its glyph with `logomark.svg` for parity.
- **iOS/Android:** mark centered on gradient, safe area 80%; Android adaptive
  (foreground mark / background gradient).
- **Favicon:** `favicon.svg` (+ export 32/180px PNG).

## Illustration style
Geometric, rounded, 2px stroke, duotone (brand + growth), soft grain. Calm
scenes (desk, plant, book), never a staring camera. Empty states use a single
friendly line illustration.

## Mascot (optional, ❌ future)
“Guide” — a soft rounded owl-lamp hybrid (wisdom + focus light). Appears only in
onboarding + achievement unlocks; never during study (avoids distraction).
