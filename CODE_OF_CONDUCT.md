# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, welcoming, and constructive. Harassment and
discrimination of any kind are not tolerated. Maintainers may remove, edit, or
reject contributions and comments that violate this code, and may ban
contributors for behavior they deem inappropriate.

To report unacceptable behavior, contact the maintainers via the repository's
Security tab or a private channel listed in the project README.
